# Printf

---

## Basic

| Type        | Printf       |
| ----------- | ------------ |
| short       | `%hd`        |
| int         | `%d` or `%i` |
| long        | `%ld`        |
| long long   | `%lld`       |
| float       | `%f`         |
| double      | `%f`         |
| long double | `%Lf`        |
| character   | `%c`         |
| string      | `%s`         |
| size_t      | `%zu`        |
| pointer     | `%p`         |

---

## Unsigned

| Type               | Printf |
| ------------------ | ------ |
| unsigned short     | `%hu`  |
| unsigned int       | `%u`   |
| unsigned long      | `%lu`  |
| unsigned long long | `%llu` |
| signed char        | `%hhd` |
| unsigned char      | `%hhu` |

---

## Others

| Type        | Printf       |
| ----------- | ------------ |
| Binary      | `%b`         |
| Octal       | `%0`         |
| Hexadecimal | `%x` or `%X` |

> [!NOTE]
> Binary specifier is only supported on newer C libraries
