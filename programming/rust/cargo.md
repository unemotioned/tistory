# Cargo

How to use cargo with rust project.

## Table of Contents

- [Create Project](#create-project)
- [Compile](#compile)
- [Build](#build)

---

## Create Project

```sh
cargo new {project-name}

# inside a existing directory
cargo init
```

---

## Compile

Compile and run.

```sh
cargo run
```

---

## Build

```sh
cargo build

# more optimized
cargo build --release
```
