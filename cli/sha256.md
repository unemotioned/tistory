## File

```sh
sha256sum <file-name>
```

Example output:

```txt
ff5edb2daf51ca07df9b0613e96702777e8342c5811df5e6927face6f4172b23  foobar.txt
```

---

## Echo

```sh
echo -n "foobar" | sha256sum
```

The output:

```txt
c3ab8ff13720e8ad9047dd39466b3c8974e592c2fa383d4a3960714caef0c4f2  -
```

## Check Download

Compare downloaded file's hash with checksum provided by the publisher.

```sh
printf '%s.n' '<expected-sha256> download.zip' | sha256sum --check
```
