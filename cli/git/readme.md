# [Git](https://git-scm.com/)

Version control system developed by [Linus Torvalds](https://github.com/torvalds)
just about in 2 weeks.

---

## Install

[Git Install](https://git-scm.com/install/windows)

### macOS

```sh
brew install git
```

### Arch

```sh
sudo pacman -Syu git
```

### Ubuntu

```sh
sudo apt install git
```

---

## Confirm

```sh
git --version
```
