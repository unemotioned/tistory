# [Git](https://git-scm.com/)

Version control system developed by [Linus Torvalds](https://github.com/torvalds)
just about in 2 weeks.

---

## Install

From online :[git-scm.git/install](https://git-scm.com/install/windows)

Or with package managers:

### macOS

```sh
brew install git
```

### Arch

```sh
sudo pacman -S git
```

### Ubuntu

```sh
sudo apt install git
```
