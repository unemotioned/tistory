# [Atomicparley](https://github.com/wez/atomicparsley)

How to setup album art for **M4A file**(apple music).

---

## Install

```sh
sudo pacman -Syu atomicparsley
```

---

## Usage

```sh
atomicparsley '01 CLOUDS.m4a' --artwork clouds.png
```

set `cloud.png` image as artwork of `01 CLOUDS.m4a` music file.

You can use [eyeD3](./eyed3.md) to set album art for MP3 or MP4 files.
