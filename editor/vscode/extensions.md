# Extensions

Extensions for Node.js development and general QOL enhancements.

---

## CSS Peek

Peek HTML tags id and class from CSS file.

## Code Runner

Run file with `Ctrl + Alt + N` shortcut.

## Code Spell Checker

Check typos and suggest fixes.

From `settings.json`:

```jsonc
{
  // do not diagnose as typo
  "cSpell.words": [
    "foobar"
  ]
  // do not show in problems pane
  "cSpell.diagnosticLevel": "Hint",
}
```
