# Shortcuts

Followings are [Windows shortcuts](https://code.visualstudio.com/shortcuts/keyboard-shortcuts-windows.pdf).

---

## Open

| Shortcut    | Action               |
| ----------- | -------------------- |
| Ctrl + R    | `Recent file/folder` |
| Ctrl + O    | `Open file`          |
| Ctrl + K, O | `Open folder`        |
| Ctrl + K, F | `Close folder`       |

## Search

| Shortcut         | Action            |
| ---------------- | ----------------- |
| Ctrl + Shift + P | `Command Palette` |
| Ctrl + P         | `Search file`     |
| Ctrl + Shift + O | `File symbols`    |
| Ctrl + T         | `Project symbols` |

## Pane

| Shortcut         | Action                |
| ---------------- | --------------------- |
| Ctrl + Shift + E | `Open Explorer`       |
| Ctrl + B         | `Toggle sidebar`      |
| Ctrl + Shift + M | `Toggle problems`     |
| Ctrl + ` (grave) | `Toggle terminal`     |
| Ctrl + ~ (tilde) | `Open new terminal`   |
| Ctrl + / (slash) | `Line comment toggle` |

## Tab

| Shortcut                | Action                   |
| ----------------------- | ------------------------ |
| Ctrl + W                | `Close tab`              |
| Ctrl + Shift + W        | `Close every tabs`       |
| Ctrl + Shift + T        | `Reopen closed tab`      |
| Ctrl + 1/2/3...         | `Select pane`            |
| Ctrl + \ (backslash)    | `Duplicate tab to right` |
| Ctrl + Alt + Left/Right | `Separate tab from pane` |

## Editing

| Shortcut              | Action                      |
| --------------------- | --------------------------- |
| Ctrl + L              | `Select line`               |
| Ctrl + Shift + K      | `Delete line`               |
| Ctrl + Shift + Z      | `Redo`(undo of undo)        |
| Ctrl + F              | `Find`                      |
| Ctrl + H              | `Replace`                   |
| Ctrl + ] / Ctrl + [   | `Indent / Outdent`          |
| Ctrl + Enter          | `Insert new line above`     |
| Ctrl + Shift + Enter  | `Insert new line below`     |
| Alt + Up/Down         | `Move line up/down`         |
| Alt + Shift + Up/Down | `Copy line up/down`         |
| Alt + Left Click      | `Insert cursor`             |
| Ctrl + Alt + Up/Down  | `Insert cursor above/below` |

## LSP Action

| Shortcut          | Action                 |
| ----------------- | ---------------------- |
| Ctrl + . (dot)    | `Quickfix`             |
| Alt + F8          | `Next problem`         |
| Alt + Shift + F8  | `Previous problem`     |
| F2                | `Rename`               |
| F12               | `Go to definition`     |
| Alt + F12         | `Peek definition`      |
| Shift + F12       | `Go to implementation` |
| Alt + Shift + F12 | `Show implementations` |
| Alt + Shift + F   | `Format file`          |

## Extra

| Shortcut                                       | Action          |

| Command Palette → View: Toggle Centered Layout | `Center editor` |
