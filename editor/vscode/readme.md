# Visual Studio Code

Free code editor by Microsoft written in TypeScript.

Download from : [code.visualstudio.com](https://code.visualstudio.com/)

> [!NOTE]
> **Visual Studio** and **Visual Studio Code** are different programs.

---

## Terminal Commands

```powershell
# open current directory with new window
code .

# open specified file using existing instance
code -r hello.js
```

`-r`: `--reuse-window`

Read [os/windows/powershell.md](/os/windows/powershell.md) for more.
